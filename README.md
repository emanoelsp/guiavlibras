# Guia VLIBRAS para Next.js

Este projeto é um guia interativo completo para implementar o VLIBRAS (tradutor de Libras) em aplicações Next.js.

## 🚀 Sobre o Projeto

O VLIBRAS é uma ferramenta essencial de acessibilidade que traduz conteúdo em português para Língua Brasileira de Sinais (Libras), tornando sites acessíveis para pessoas surdas ou com deficiência auditiva.

Este guia fornece:
- Instruções passo a passo para App Router e Pages Router
- Exemplos de código completos e funcionais
- Página de demonstração interativa
- Dicas de TypeScript e melhores práticas

## 📦 Instalação

\`\`\`bash
# Clone o repositório
git clone https://github.com/emanoelsp/guiavlibras.git

# Entre no diretório
cd guiavlibras

# Instale as dependências
npm install

# Execute o projeto
npm run dev
\`\`\`

Acesse [http://localhost:3000](http://localhost:3000) para ver o guia em ação.

## 📖 Como Usar

1. Acesse a página principal para ler o guia completo
2. Escolha entre App Router ou Pages Router
3. Siga os passos de implementação
4. Visite a página de exemplo para ver o VLIBRAS em ação
5. Clique no ícone azul no canto inferior direito para testar
